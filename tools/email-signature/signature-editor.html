Pasting into Apple Mail's signature box loses the layout and the phone stacking, so put the HTML straight into Mail's signature file:

  1. In Mail → Settings → Signatures, choose the account, click +, and name it Three Stars. Leave the placeholder text and leave "Always match my default message font" unchecked. Quit Mail.
  2. In Finder, press Cmd+Shift+G and go to ~/Library/Mobile Documents/com~apple~mail/Data/V2/Signatures/ (if that's empty or missing, use ~/Library/Mail/V10/MailData/Signatures/).
  3. Sort by Date Modified and open the newest .mailsignature file in TextEdit.
  4. Keep the header lines at the top (Content-Type, Message-Id, Mime-Version…). Delete everything after the first blank line, paste what Copy HTML gives you, and save.
  5. Lock the file: right-click → Get Info → tick Locked. (To update it later, untick Locked, paste the new HTML, and lock it again.)
  6. Reopen Mail. The settings preview may look plain, but new messages show the real signature. Send yourself a test and open it on a phone.

Gmail on the web

  1. Click Copy signature above.
  2. In Gmail: gear → See all settings → General → Signature → Create new. Name it Three Stars.
  3. Click in the signature box and paste (Cmd+V / Ctrl+V).
  4. Under Signature defaults, choose Three Stars for new emails and for replies/forwards.
  5. Scroll down and click Save Changes. Repeat for each "send from" address.

Gmail removes the phone-stacking rule. On phones the columns still wrap, but less neatly, and in layouts A and C the divider line can stay next to the details. Layout B wraps most cleanly in Gmail.

These settings only apply when sending from gmail.com or the Gmail app. Emails sent from Apple Mail or Outlook use that app's signature, even for a Google account.

Outlook for Mac

  1. Click Copy signature.
  2. Outlook → Settings → Signatures → +. Name it Three Stars, select the placeholder text, and paste.
  3. Close the editor to save. Under Choose default signature, set it for new messages and replies/forwards.

New Outlook for Windows and Outlook on the web

  1. Click Copy signature.
  2. Gear (Settings) → Accounts → Signatures → + New signature. Name it Three Stars and paste.
  3. Under Select default signatures, choose it for new messages and replies/forwards. Click Save.

Classic Outlook for Windows

  1. File → Options → Mail → Signatures → New. Name it Three Stars, type any placeholder text, and click OK. Close Outlook.
  2. Press Windows+R, type %APPDATA%\Microsoft\Signatures, and press Enter.
  3. Right-click Three Stars.htm → Open with → Notepad. Select everything and delete it.
  4. Click Copy for Outlook (Windows), paste into Notepad, and save as UTF-8.
  5. Reopen Outlook and set it as the default signature. Don't edit it in Outlook's signature editor after this, or Outlook will rewrite the file.

Classic Outlook for Windows stays side by side on every screen and shows the name in Georgia. Some Outlook recipients will see the logo only after clicking "Download pictures".
